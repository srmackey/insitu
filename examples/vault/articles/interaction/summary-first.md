# Summary first

Example-vault style rule. Off by default. Use it only when a full reply would be too expensive to read in one sitting.

1. Thesis first, a few sentences.
2. Then an index of two to five buckets, ordered by attention needed.
3. Expand one bucket when asked.

This is sample text for Insitu demos, not a personal standing rule.
