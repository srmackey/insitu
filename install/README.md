# Install drop-ins

These files ship with the Insitu *server*, not inside a user's vault.

Two layers. Do not mix them. See `DESIGN.md` §10.

**Routers** (install once, user-global). They tell the host the MCP exists, treat the generated protocol as binding, pull on-demand articles with `get_article`, and rematerialize if the header is stale. If other host files this host loads are missing, they tell the agent to retrieve the multi-platform pack and write them. They do not contain the composed pack or pack bodies.

Copy or symlink:

- `routers/cursor.mdc` → `~/.cursor/rules/insitu-router.mdc` (`alwaysApply: true`)
- `routers/claude.md` → `~/.claude/rules/insitu-router.md` (no `paths` frontmatter)
- `routers/grok.md` → `~/.grok/rules/insitu-router.md`
- `AGENTS.md` — optional constitution hook (insurance, not the injector). Never generated by `materialize`.
- `mcp.json.examples.md` — `mcp.json` snippets, `INSITU_HOME` / `--vault`

**Protocol pack** is not an install file. `materialize` writes `PROTOCOL.md` plus per-project host adapters from `config/surfaces.yaml`.
